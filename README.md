# 我的衣橱 WARDROBE · 个人衣物管理 PWA

一个纯前端、零后端、可离线使用的个人衣物管理应用。数据全部保存在你自己的浏览器（IndexedDB）里，不会上传到任何服务器。

## 功能

- **衣物档案**：拍照 / 上传图片记录每件衣物，填写分类、颜色、品牌、尺码、材质、购买价、购买日期、季节、场合等；包、皮带、鞋、帽子等配饰也用同一套模型管理，支持自定义分类。
- **每日穿搭**：记录每天穿了哪几件，可加备注。
- **日历**：在月历上查看哪些天有穿搭记录。
- **数据洞察**：
  - 衣物数量、衣物总价值、累计穿着次数；
  - 品类分布（数量与金额）；
  - 每件衣物的**穿着次数、单次成本（CPW = 价格 / 穿着次数）、闲置天数**；
  - 闲置提醒（30–90 天 / 90 天以上）与各类单品排行。
- **离线 / 可安装**：基于 Service Worker，支持离线打开，并可“添加到主屏幕”像原生 App 一样使用。
- **数据备份**：在设置中导出 / 导入 JSON 备份，方便换机。

## 技术栈

- 单文件 HTML + 原生 JavaScript（无框架、无构建步骤）
- IndexedDB 存储
- Service Worker 离线缓存 + Web App Manifest
- Soft Brutalism（柔和粗野主义）视觉风格

## 本地使用

直接用浏览器打开 `index.html` 即可；若需要完整的离线 / 安装能力，请通过 HTTP(S) 访问（例如 `python3 -m http.server`），Service Worker 不支持 `file://` 协议。

## 部署

本仓库通过 GitHub Pages 发布，入口为根目录的 `index.html`。
